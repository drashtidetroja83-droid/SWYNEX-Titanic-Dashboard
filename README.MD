# Titanic Survival Analysis Dashboard

## 1. Project Overview
This project analyzes the Titanic passenger dataset to understand passenger survival patterns using Python and Power BI.

## 2. Problem Statement
The main objective of this project is to analyze Titanic passenger data and identify survival patterns based on gender, passenger class, age, and other available information.

## 3. Dataset Information
The Titanic dataset contains passenger information such as:
- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- Fare
- Cabin
- Embarked

## 4. Data Cleaning
Data cleaning was performed using Microsoft Excel.

- Checked missing values.
- Handled missing Age values.
- Filled missing Cabin values with "Unknown".
- Checked for duplicate records.
- Removed unnecessary columns.
- Prepared the cleaned dataset for further analysis.
  
## 5. Exploratory Data Analysis (EDA)
Exploratory Data Analysis of the Titanic dataset using Python. Includes missing value checks, survival statistics, gender-wise survival analysis, passenger class analysis, average ticket fare calculation, five useful insights, and charts to identify trends and patterns in passenger survival.

## 6. Power BI Dashboard
An interactive dashboard was created using Power BI to present passenger survival information through cards and charts.

The dashboard includes:
- Total passengers.
- Total survivors.
- Average passenger fare.
- Survival by gender.
- Survival by passenger class.
- Survival by age.

## 7. Key Business Insights
- Out of 891 passengers, 342 survived.
- Female passengers accounted for 233 survivors.
- Male passengers accounted for 109 survivors.
- The dashboard helps compare survival patterns across passenger groups.
- Data visualization makes the findings easier to understand.

## 8. Tools and Technologies

## 9. Project Files
This repository contains Python code, EDA screenshots, and Power BI dashboard files.

## 10. Conclusion
This project demonstrates how data cleaning, exploratory data analysis, and visualization can be used to understand passenger survival patterns in the Titanic dataset.
